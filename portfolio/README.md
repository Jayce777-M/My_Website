# Jireh.EXE — Developer Universe

An immersive, 3D portfolio for Jireh, focused on full-stack engineering and applied AI.

## Stack

- Next.js App Router + TypeScript
- React Three Fiber + Three.js
- Drei for 3D helpers
- Framer Motion
- Custom CSS design system

## Run locally

Requirements: Node.js 20.9 or newer.

```bash
cd portfolio
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy to Vercel

1. Import the existing GitHub repository.
2. Set **Root Directory** to `portfolio`.
3. Keep the framework preset as Next.js.
4. Deploy.
